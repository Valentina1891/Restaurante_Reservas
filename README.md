# 🍽️ Pudu Restaurante – Landing Page & Sistema de Reservas

Proyecto de práctica y portafolio donde se desarrolla una **Landing Page para un restaurante**, incorporando un **sistema de reservas y autenticación**, con frontend moderno y backend desplegado en la nube.

El proyecto cumple con criterios de **diseño responsive**, buenas prácticas de desarrollo web y separación frontend/backend.

🌐 **Sitio web:**
👉 [https://valentina1891.github.io/Restaurante_Reservas/](https://valentina1891.github.io/Restaurante_Reservas/)

⚙️ **API (backend):**
👉 [https://restaurante-reservas.onrender.com](https://restaurante-reservas.onrender.com)

---

## 🚀 Características

### 🎨 Frontend

* 📱 **Diseño responsive**: adaptable a móviles, tablets y escritorio
* 📌 **Navbar funcional**: menú hamburguesa en pantallas pequeñas
* 🖼️ **Sección Hero**: imagen principal, título, subtítulo y botones de acción
* 🍲 **Menú de platos**: listado dinámico con cards
* 📅 **Reservas**: formulario integrado al backend
* 🔐 **Autenticación**: login, registro y manejo de sesión
* 🦶 **Footer**: enlaces a redes sociales y créditos

### 🧠 Backend

* 🔑 Autenticación con JWT (cookies httpOnly)
* 👤 Roles de usuario (usuario / admin)
* 📦 CRUD de comidas
* 📋 Gestión de reservas
* 🌍 API REST desplegada en Render
* 🗄️ Base de datos MongoDB Atlas
